# Auto Tab Timer - Chrome Web Store 描述（zh-CN）

Auto Tab Timer 是一款浏览器扩展和标签页倒计时计时器，可让您在设定时间后自动关闭任意标签页。  
您可以为标签页设置计时器，使其在倒计时结束后自动关闭，帮助避免标签页长时间保持打开状态。非常适合视频播放、后台标签页以及夜间浏览。

适用于所有基于 Chromium 的浏览器。

---

## 功能

- 完整的标签页计时器控制  
  可随时启动、暂停、继续、重置或取消任何标签页计时器。

- 自动关闭标签页  
  当倒计时归零时，标签页会自动关闭。

- 标签页倒计时计时器  
  使用 Auto Tab Timer 作为简单的标签页倒计时工具，在几分钟或几小时后自动关闭标签页。

- 每个计时器的完成操作  
  您可以选择计时器结束时执行的操作：自动关闭标签页，或使用“仅通知我”保持标签页打开并接收提醒。

- 可自定义通知  
  当标签页计时器结束时接收通知，让您在标签页关闭之前得到提醒。

- 实时倒计时显示  
  在扩展程序弹出窗口中查看实时倒计时，并管理所有正在运行的标签页计时器。

- 标签页计时器状态显示  
  扩展图标会显示带有活动计时器的标签页剩余时间，方便快速识别哪些标签页即将关闭。

- 快速输入控制  
  小时、分钟和秒输入框支持鼠标滚轮调整，让计时器设置更加快捷。

- 来自此开发者的更多扩展  
  在安装引导页和“最新更新”页面中，Auto Tab Timer 包含一个“来自此开发者的更多扩展”区域。该区域会显示同一开发者的其他扩展链接，并在没有推广卡片时显示“查看所有扩展”的开发者主页链接。

## 为什么使用 Auto Tab Timer？

- 在设定时间后自动关闭任意标签页
- 使用标签页计时器或倒计时控制标签页关闭时间
- 通过自动关闭标签页保持浏览器整洁
- 睡前观看视频时无需担心标签页一直保持打开
