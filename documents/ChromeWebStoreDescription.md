# Auto Tab Timer - Chrome Web Store Description

Auto Tab Timer is a browser extension and tab countdown timer that lets you automatically close any tab after a set time.  
Use it to set timers for tabs so they close automatically, helping prevent tabs from staying open too long. It is ideal for videos, background tabs, and overnight browsing.

Works on Chromium-based browsers.

---

## Features

- Full Tab Timer Controls  
  Start, pause, resume, reset, or cancel any tab timer at any time.

- Automatic Tab Closing  
  Tabs close automatically when their countdown timer reaches zero.

- Tab Countdown Timer  
  Use Auto Tab Timer as a simple tab countdown timer to close tabs after minutes or hours.

- Per-Timer Completion Actions  
  Choose what happens when a timer finishes. Close the tab automatically or use "Notify me only" to keep the tab open and receive a reminder.

- Customizable Notifications  
  Receive a notification when a tab timer finishes so you know before a tab closes.

- Real-Time Countdown Display  
  View a live countdown and manage all active tab timers directly from the extension popup.

- Timer Status on Tabs  
  The extension icon shows the remaining time for tabs with active timers, making it easy to identify which tabs will close soon.

- Quick Input Controls  
  Hours, minutes, and seconds fields support mouse-wheel adjustment for faster timer setup.

- More Extensions from this Developer  
  On the onboarding and "What's New" pages, Auto Tab Timer includes a section called "More extensions from this developer." It shows links to other extensions from the same developer, and may show a "View all extensions" developer profile link if promotion cards are unavailable.

- Automatically close any tab after a chosen amount of time
- Use a tab timer or tab countdown timer to control when tabs close
