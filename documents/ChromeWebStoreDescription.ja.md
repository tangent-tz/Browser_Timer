# Auto Tab Timer - Chrome Web Store 説明（JA）

Auto Tab Timer は、設定した時間後に任意のタブを自動的に閉じることができるブラウザー拡張機能およびタブ用カウントダウンタイマーです。  
タブにタイマーを設定すると、カウントダウン終了時に自動で閉じられます。タブが長時間開きっぱなしになるのを防ぎます。動画視聴、バックグラウンドタブ、就寝前のブラウジングに最適です。

Chromium ベースのブラウザーで動作します。

---

## 機能

- 完全なタブタイマー操作  
  タブタイマーをいつでも開始、一時停止、再開、リセット、またはキャンセルできます。

- タブの自動クローズ  
  カウントダウンタイマーが 0 になると、タブが自動的に閉じます。

- タブ用カウントダウンタイマー  
  Auto Tab Timer をシンプルなタブタイマーとして使用し、数分または数時間後にタブを自動的に閉じることができます。

- タイマーごとの完了アクション  
  タイマー終了時の動作を選択できます。タブを自動的に閉じるか、「通知のみ」を選択してタブを開いたまま通知を受け取ることができます。

- カスタマイズ可能な通知  
  タブタイマーが終了すると通知を受け取り、タブが閉じる前に確認できます。

- リアルタイムカウントダウン表示  
  拡張機能のポップアップからライブカウントダウンを確認し、すべてのアクティブなタブタイマーを管理できます。

- タブ上のタイマー状態表示  
  拡張機能アイコンに、タイマーが有効なタブの残り時間が表示されるため、どのタブがもうすぐ閉じるか簡単に確認できます。

- クイック入力コントロール  
  時間、分、秒の入力欄はマウスホイールで調整でき、タイマーをより素早く設定できます。

- このデベロッパーの他の拡張機能  
  オンボーディングページと「最新情報」ページには、「このデベロッパーの他の拡張機能」セクションがあります。ここでは同じデベロッパーの他の拡張機能へのリンクを表示し、プロモーションカードを表示できない場合は「すべての拡張機能を見る」というデベロッパープロフィールへのリンクを表示します。

## 最近の更新（バージョン 1.3.0）

- より安定したタイマー開始のために入力処理を改善
- 00:00:00 でタイマーを開始しようとすると検証エラーが表示されるようになりました
- 「通知のみ」は常に通知を送信し、タブを閉じません
- 新しいインストール用オンボーディングと、1.3.0 用の一度だけ表示される更新ページを追加
- オンボーディング/更新ページに「このデベロッパーの他の拡張機能」セクションを追加
- 時間入力欄でマウスホイールによる調整に対応

---

## Auto Tab Timer を使う理由

- 任意のタブを指定した時間後に自動で閉じる
- タブタイマーまたはカウントダウンでタブを閉じるタイミングを管理
- タブの自動クローズでブラウザーを整理
- 動画を見ながら眠ってしまってもタブを開きっぱなしにしない
