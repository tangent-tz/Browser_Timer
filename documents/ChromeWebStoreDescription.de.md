# Auto Tab Timer - Chrome Web Store Beschreibung (DE)

Auto Tab Timer ist eine Browser-Erweiterung und ein Tab-Countdown-Timer, mit dem Sie jeden Tab automatisch nach einer festgelegten Zeit schließen können.  
Verwenden Sie ihn, um Timer für Tabs zu setzen, damit sie automatisch geschlossen werden. So verhindern Sie, dass Tabs zu lange geöffnet bleiben. Ideal für Videos, Hintergrund-Tabs und nächtliches Surfen.

Funktioniert in Chromium-basierten Browsern.

---

## Funktionen

- Vollständige Tab-Timer-Steuerung  
  Starten, pausieren, fortsetzen, zurücksetzen oder beenden Sie jeden Tab-Timer jederzeit.

- Automatisches Schließen von Tabs  
  Tabs schließen automatisch, sobald ihr Countdown-Timer null erreicht.

- Tab-Countdown-Timer  
  Verwenden Sie Auto Tab Timer als einfachen Tab-Countdown-Timer, um Tabs nach Minuten oder Stunden zu schließen.

- Abschlussaktionen pro Timer  
  Wählen Sie, was passiert, wenn ein Timer endet. Schließen Sie den Tab automatisch oder verwenden Sie „Nur benachrichtigen“, um den Tab geöffnet zu lassen und eine Erinnerung zu erhalten.

- Anpassbare Benachrichtigungen  
  Erhalten Sie eine Benachrichtigung, wenn ein Tab-Timer endet, damit Sie es wissen, bevor ein Tab geschlossen wird.

- Countdown-Anzeige in Echtzeit  
  Sehen Sie einen Live-Countdown und verwalten Sie alle aktiven Tab-Timer direkt im Popup der Erweiterung.

- Timer-Status auf Tabs  
  Das Erweiterungssymbol zeigt die verbleibende Zeit für Tabs mit aktivem Timer an, sodass Sie leicht erkennen können, welche Tabs bald geschlossen werden.

- Schnelle Eingabesteuerung  
  Die Felder für Stunden, Minuten und Sekunden unterstützen die Anpassung mit dem Mausrad, um Timer schneller einzustellen.

- Weitere Erweiterungen dieses Entwicklers  
  Auf den Onboarding- und „Was ist neu“-Seiten enthält Auto Tab Timer einen Bereich „Weitere Erweiterungen dieses Entwicklers“. Dort werden Links zu anderen Erweiterungen desselben Entwicklers angezeigt. Falls keine Promo-Karten verfügbar sind, kann stattdessen ein Link „Alle Erweiterungen ansehen“ zum Entwicklerprofil angezeigt werden.

## Warum Auto Tab Timer verwenden?

- Jeden Tab automatisch nach einer gewählten Zeit schließen
- Einen Tab-Timer oder Countdown verwenden, um zu steuern, wann Tabs geschlossen werden
- Den Browser organisiert halten durch automatisches Schließen von Tabs
- Videos ansehen und einschlafen, ohne offene Tabs zu hinterlassen
