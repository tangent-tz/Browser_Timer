# Auto Tab Timer - Descripción Chrome Web Store (ES)

Auto Tab Timer es una extensión de navegador y un temporizador de cuenta regresiva para pestañas que te permite cerrar automáticamente cualquier pestaña después de un tiempo determinado.  
Úsalo para establecer temporizadores en pestañas para que se cierren automáticamente, ayudando a evitar que las pestañas permanezcan abiertas demasiado tiempo. Es ideal para videos, pestañas en segundo plano y navegación nocturna.

Funciona en navegadores basados en Chromium.

---

## Funciones

- Control completo del temporizador de pestañas  
  Inicia, pausa, reanuda, reinicia o cancela cualquier temporizador de pestaña en cualquier momento.

- Cierre automático de pestañas  
  Las pestañas se cierran automáticamente cuando el temporizador de cuenta regresiva llega a cero.

- Temporizador de cuenta regresiva para pestañas  
  Usa Auto Tab Timer como un temporizador simple para cerrar pestañas después de minutos u horas.

- Acciones de finalización por temporizador  
  Elige qué sucede cuando un temporizador termina. Cierra la pestaña automáticamente o usa "Solo notificarme" para mantener la pestaña abierta y recibir un recordatorio.

- Notificaciones personalizables  
  Recibe una notificación cuando un temporizador de pestaña termine para saber antes de que una pestaña se cierre.

- Visualización de cuenta regresiva en tiempo real  
  Consulta una cuenta regresiva en vivo y administra todos los temporizadores activos directamente desde el popup de la extensión.

- Estado del temporizador en las pestañas  
  El icono de la extensión muestra el tiempo restante de las pestañas con temporizadores activos, lo que facilita identificar cuáles se cerrarán pronto.

- Controles rápidos de entrada  
  Los campos de horas, minutos y segundos permiten ajustes con la rueda del ratón para configurar temporizadores más rápidamente.

- Más extensiones de este desarrollador  
  En las páginas de onboarding y de "Novedades", Auto Tab Timer incluye una sección "Más extensiones de este desarrollador". Esta sección muestra enlaces a otras extensiones del mismo desarrollador y puede mostrar un enlace "Ver todas las extensiones" al perfil del desarrollador cuando no haya tarjetas promocionales disponibles.

## Actualizaciones recientes (Versión 1.3.0)

- Mejora en el manejo de la entrada del temporizador para un inicio más predecible
- Iniciar un temporizador con 00:00:00 ahora muestra un error de validación
- "Solo notificarme" siempre envía una notificación y nunca cierra la pestaña
- Se añadieron páginas de bienvenida al instalar y una página única de actualización para la versión 1.3.0
- Se añadió la sección "Más extensiones de este desarrollador" en las páginas de onboarding/actualización
- Los campos de tiempo ahora permiten ajuste con la rueda del ratón

## ¿Por qué usar Auto Tab Timer?

- Cierra automáticamente cualquier pestaña después de un tiempo elegido
- Usa un temporizador de pestañas o cuenta regresiva para controlar cuándo se cierran las pestañas
- Mantén tu navegador organizado con el cierre automático de pestañas
- Mira videos antes de dormir sin preocuparte por pestañas abiertas
